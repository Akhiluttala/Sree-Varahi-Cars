Sree Varahi Cars | Website demo

Extract the entire ZIP, then open index.html in a browser. No installation or server is required. Keep the files and images folder together. To host it, upload the extracted files to a static web host.

Pages: index.html (home), about.html, location.html, contact.html, enquiry.html.
Edit style.css for colours and layout, and script.js for the WhatsApp enquiry workflow.

The example car images are locally bundled, generated illustrations of vehicle categories. Replace them with dealership photos before displaying actual stock. The review excerpts and rating are from the supplied Google Maps profile.

Visitors can preview an enquiry locally. Opening WhatsApp requires internet access and the visitor sends the message there. A visit is confirmed only after the showroom replies. Directions open Google Maps.
